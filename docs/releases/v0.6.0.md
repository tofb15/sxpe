- Daily-driver package editor milestone (M6): validate report, package compare, find references, XML/ITUN and NMAP editors, Downloads folder scan, neighborhood/world/DBC layout-lock honesty, S3SA external viewer, read-only Sims3Pack inspect, Linux Qt GUI smoke path.

- Documentation overhaul: README quick starts, `docs/user-guide.md`, `docs/cli-mcp.md`, `docs/workflows.md`, building/release notes.

## Install

### Linux CLI + MCP (published)

1. Download `sxpe-0.6.0-linux-x64-cli.tar.gz` from this Release.
2. Extract and run `sxpe` / `sxpe_mcp`.

### Windows portable (local build)

1. Build and package: `build.bat`, then `package.bat` (see [docs/building.md](../building.md)).
2. Output: `dist/sxpe-0.6.0-windows-x64.zip` — unzip; keep DLLs and plugin folders next to the executables.
3. Run `SXPE.bat`. CLI: `sxpe-cli.bat`. MCP: `sxpe-mcp.bat`.

## Building from source

See [docs/building.md](../building.md). Version sources: `CMakeLists.txt` `PROJECT_VERSION` and `vcpkg.json` `"version-string"` (both **0.6.0**).

## Limits (unchanged honesty)

- Sims 3 only; no Sims 4 profile.
- No full 3D mesh / CLIP playback.
- No Store/DRM Sims3Pack.
- Layout-locked `.nhd` / `.world` / `.dbc` (safe in-place replace only).
- No third-party GUI plugins.
