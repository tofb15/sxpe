# SXPE 0.7.3 - release notes

**Tag:** `v0.7.3`

Published on GitHub as a **pre-release / Beta**. PATCH hotfix on 0.7.2 ([versioning.md](../versioning.md)): merged CC packages no longer crash The Sims 3.

## Highlights

Since [v0.7.2](v0.7.2.md):

- **Merge no longer crashes the game.** Community CC NameMaps often use a hashed instance (same FNV as the CASP). 0.7.2 copied those as separate NMAP resources. The Sims 3 then crashed when the merged package was in `Mods\Packages`. SXPE now concatenates **every** source NMAP into one canonical `0166038C:0:0` at index 0, matching s3pe.
- **Un-merge still works in-package.** SXMM (`53584D4D:0:1`) stays in the merge (no sidecar file) and is written with the same TS3 index flags as other resources. Each source’s original NameMap TGI is restored on un-merge.

Re-merge any packages created with 0.7.2 (or earlier SXPE) before putting them in Mods.

`sxpe --version` prints branch, commit, and compile time under the `sxpe 0.7.3` line. MCP `serverInfo.version` is still the product version only.

## Install

### Windows portable

1. Download / unzip `sxpe-0.7.3-windows-x64.zip` (or build locally with `package.bat`).
2. Run `SXPE.bat`. CLI: `sxpe-cli.bat`. MCP: `sxpe-mcp.bat`.

### Windows CLI + MCP

1. Download / unzip `sxpe-0.7.3-windows-x64-cli.zip` (or `scripts/package.ps1 -NoGui`).
2. Run `sxpe-cli.bat` / `sxpe-mcp.bat`.

### Linux CLI + MCP

1. Download / extract `sxpe-0.7.3-linux-x64-cli.tar.gz` (or run `./scripts/package-linux.sh --no-gui`).
2. Run `./sxpe` / `./sxpe_mcp` (or the `*-cli.sh` / `*-mcp.sh` launchers).

### Linux GUI

1. Download / extract `sxpe-0.7.3-linux-x64.tar.gz` (or `./scripts/package-linux.sh` when `sxpe_gui` exists).
2. Run `./SXPE.sh`. System/official Qt 6.5+ must resolve at runtime (not vendored). See [docs/building.md](../building.md).

## Building from source

See [docs/building.md](../building.md). Version sources: `CMakeLists.txt` `PROJECT_VERSION` and `vcpkg.json` `"version-string"` (both **0.7.3**).

## Limits (honesty)

- Sims 3 only; no Sims 4 profile.
- No full 3D mesh / CLIP playback.
- No Store/DRM Sims3Pack.
- Layout-locked `.nhd` / `.world` / `.dbc`.
- Third-party GUI plugins permanently unsupported (#60).
