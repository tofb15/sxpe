## Highlights

M7 / community work landed on `dev` since 0.6.0:

- Large-merge resilience (caps, progress, temp hygiene)
- Merge conflict hygiene (leftovers, duplicate TGI policy)
- Huge-package open performance (index-first, caps, RO threshold)
- Long-op cancel + rollback for merge/import
- First-run / merge onboarding for non-experts
- Game/file lock detection before open and save
- Broader DDS decode/replace coverage
- Typed OBJD/CASP editors with dryRun + undo
- REFS editor and outbound listRefs
- Limited Sims3Pack pack authoring
- Richer RCOL summary and safe chunk replace
- CLIP metadata editor, safe fields, batch exportAs
- Third-party GUI plugins permanently unsupported (#60)
- Linux packaging + docs parity with Windows (#52)

## Install

### Windows portable (local build until #54)

1. Build and package: `build.bat`, then `package.bat` (see [docs/building.md](../building.md)).
2. Output: `dist/sxpe-0.7.0-windows-x64.zip` — unzip; keep DLLs and **Qt** plugin folders (`platforms/`, etc.) next to the executables.
3. Run `SXPE.bat`. CLI: `sxpe-cli.bat`. MCP: `sxpe-mcp.bat`.

### Linux CLI + MCP

1. Run `./scripts/package-linux.sh --no-gui` (or download from the Release once `v0.7.0` is published).
2. Extract / run `./sxpe` / `./sxpe_mcp` (or the `*-cli.sh` / `*-mcp.sh` launchers).

### Linux GUI

Build with Qt 6.5+ present ([docs/building.md](../building.md)), or package with `./scripts/package-linux.sh` when `sxpe_gui` exists. System/official Qt must resolve at runtime.

## Building from source

See [docs/building.md](../building.md). Version sources: `CMakeLists.txt` `PROJECT_VERSION` and `vcpkg.json` `"version-string"` (both **0.7.0**).

## Limits (honesty)

- Sims 3 only; no Sims 4 profile.
- No full 3D mesh / CLIP playback.
- No Store/DRM Sims3Pack.
- Layout-locked `.nhd` / `.world` / `.dbc`.
- Third-party GUI plugins permanently unsupported (#60).
