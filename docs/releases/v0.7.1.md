# SXPE 0.7.1 - release notes

**Tag:** `v0.7.1`

Published on GitHub as a **pre-release / Beta**. PATCH on 0.7.0 ([versioning.md](../versioning.md)): same capabilities, GUI honesty and Help polish.

## Published assets

| Asset | Status |
| --- | --- |
| `sxpe-0.7.1-windows-x64.zip` | **On this Release** - portable GUI + CLI + MCP + Qt plugins + MSVC CRT. Unzip and run `SXPE.bat`. |
| `sxpe-0.7.1-windows-x64-cli.zip` | **On this Release** - Windows CLI + MCP only (no Qt / no `sxpe_gui`). Unzip and run `sxpe-cli.bat` / `sxpe-mcp.bat`. |
| `sxpe-0.7.1-linux-x64-cli.tar.gz` | **On this Release** - Linux CLI + MCP (no Qt). Rebuild with `scripts/package-linux.sh --no-gui`. |
| `sxpe-0.7.1-linux-x64.tar.gz` | **On this Release** - Linux CLI + MCP + `sxpe_gui`. Qt is **not** vendored; system or official Qt 6.5+ must resolve at runtime. |

## Highlights

Since [v0.7.0](v0.7.0.md):

- **Tools menu** grouping, enablement (no silent no-ops), and dialog polish: Search results table, Un-merge assistant, Scan folder progress, FNV copy, Compare filters, Validate hotspots ([#104](https://github.com/tofb15/sxpe/pull/104)).
- **Scan folder** Path column no longer clips Windows paths to `D:...` ([#105](https://github.com/tofb15/sxpe/pull/105)).
- **Help** windows restyled (Contents, Welcome, Common tasks, Check for update, Feedback, Warranty, Licence). **About** shows branch, commit, compile UTC, and original vs fork, with a link to [github.com/tofb15/sxpe](https://github.com/tofb15/sxpe) ([#107](https://github.com/tofb15/sxpe/pull/107)).
- Help → **Welcome…** reopens the first-run tip. Help → **Feedback…** opens GitHub Issues (with a short notice).
- Ctrl+S / File → Save on an untitled package opens Save As.
- Check for update prefers a newer Beta tag over GitHub `/releases/latest` (which ignores prereleases).
- README and docs for mixed audiences; [version bump rules](../versioning.md).

`sxpe --version` prints branch, commit, and compile time under the `sxpe 0.7.1` line. MCP `serverInfo.version` is still the product version only.

## Install

### Windows portable

1. Download / unzip `sxpe-0.7.1-windows-x64.zip` (or build locally with `package.bat`).
2. Run `SXPE.bat`. CLI: `sxpe-cli.bat`. MCP: `sxpe-mcp.bat`.

### Windows CLI + MCP

1. Download / unzip `sxpe-0.7.1-windows-x64-cli.zip` (or `scripts/package.ps1 -NoGui`).
2. Run `sxpe-cli.bat` / `sxpe-mcp.bat`.

### Linux CLI + MCP

1. Download / extract `sxpe-0.7.1-linux-x64-cli.tar.gz` (or run `./scripts/package-linux.sh --no-gui`).
2. Run `./sxpe` / `./sxpe_mcp` (or the `*-cli.sh` / `*-mcp.sh` launchers).

### Linux GUI

1. Download / extract `sxpe-0.7.1-linux-x64.tar.gz` (or `./scripts/package-linux.sh` when `sxpe_gui` exists).
2. Run `./SXPE.sh`. System/official Qt 6.5+ must resolve at runtime (not vendored). See [docs/building.md](../building.md).

## Building from source

See [docs/building.md](../building.md). Version sources: `CMakeLists.txt` `PROJECT_VERSION` and `vcpkg.json` `"version-string"` (both **0.7.1**).

## Limits (honesty)

- Sims 3 only; no Sims 4 profile.
- No full 3D mesh / CLIP playback.
- No Store/DRM Sims3Pack.
- Layout-locked `.nhd` / `.world` / `.dbc`.
- Third-party GUI plugins permanently unsupported (#60).
