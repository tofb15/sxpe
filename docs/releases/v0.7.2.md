# SXPE 0.7.2 - release notes

**Tag:** `v0.7.2`

Published on GitHub as a **pre-release / Beta**. PATCH on 0.7.1 ([versioning.md](../versioning.md)): same capabilities; app icon, CLI/MCP polish, and Linux GUI packaging.

## Published assets

| Asset | Status |
| --- | --- |
| `sxpe-0.7.2-windows-x64.zip` | **On this Release** - portable GUI + CLI + MCP + Qt plugins + MSVC CRT. Unzip and run `SXPE.bat`. |
| `sxpe-0.7.2-windows-x64-cli.zip` | **On this Release** - Windows CLI + MCP only (no Qt / no `sxpe_gui`). Unzip and run `sxpe-cli.bat` / `sxpe-mcp.bat`. |
| `sxpe-0.7.2-linux-x64-cli.tar.gz` | **On this Release** - Linux CLI + MCP (no Qt). Rebuild with `scripts/package-linux.sh --no-gui`. |
| `sxpe-0.7.2-linux-x64.tar.gz` | **On this Release** - Linux CLI + MCP + `sxpe_gui`. Qt is **not** vendored; system or official Qt 6.5+ must resolve at runtime. |

## Highlights

Since [v0.7.1](v0.7.1.md):

- **App icon** on the window, Help → About, and the Windows executables (`sxpe_gui`, `sxpe`, `sxpe_mcp`).
- **CLI / MCP polish** from 0.7.1 feedback ([#108](https://github.com/tofb15/sxpe/pull/108)): `resource.list` reports `returned` / `total` and table prints `Showing N of M` (`--all` walks pages); MCP writes exact `Content-Length` framing on Windows; unknown commands suggest a nearest match; `nmap.set` / `replace` / `delete` and `resource.rename` take optional `compress`; MCP tool names match CLI kebab (`resource_find-refs`).
- **Linux GUI packaging:** official Qt 6.8 needs ICU 73 on the Ubuntu 24.04 runner; the release job now uses the Qt ICU archive instead of a 404ing `libicu73` wget.

`sxpe --version` prints branch, commit, and compile time under the `sxpe 0.7.2` line. MCP `serverInfo.version` is still the product version only.

## Install

### Windows portable

1. Download / unzip `sxpe-0.7.2-windows-x64.zip` (or build locally with `package.bat`).
2. Run `SXPE.bat`. CLI: `sxpe-cli.bat`. MCP: `sxpe-mcp.bat`.

### Windows CLI + MCP

1. Download / unzip `sxpe-0.7.2-windows-x64-cli.zip` (or `scripts/package.ps1 -NoGui`).
2. Run `sxpe-cli.bat` / `sxpe-mcp.bat`.

### Linux CLI + MCP

1. Download / extract `sxpe-0.7.2-linux-x64-cli.tar.gz` (or run `./scripts/package-linux.sh --no-gui`).
2. Run `./sxpe` / `./sxpe_mcp` (or the `*-cli.sh` / `*-mcp.sh` launchers).

### Linux GUI

1. Download / extract `sxpe-0.7.2-linux-x64.tar.gz` (or `./scripts/package-linux.sh` when `sxpe_gui` exists).
2. Run `./SXPE.sh`. System/official Qt 6.5+ must resolve at runtime (not vendored). See [docs/building.md](../building.md).

## Building from source

See [docs/building.md](../building.md). Version sources: `CMakeLists.txt` `PROJECT_VERSION` and `vcpkg.json` `"version-string"` (both **0.7.2**).

## Limits (honesty)

- Sims 3 only; no Sims 4 profile.
- No full 3D mesh / CLIP playback.
- No Store/DRM Sims3Pack.
- Layout-locked `.nhd` / `.world` / `.dbc`.
- Third-party GUI plugins permanently unsupported (#60).
